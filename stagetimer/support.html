Getting started

  1. Choose a time and click Start.
  2. Open the stage screen to show the timer on a second display.
  3. Type a message to show it to the presenter.
  4. To control it from a phone, open Settings → Remote Control and scan the code.

You can reopen the welcome guide any time from Help → Getting Started.

Common questions

It says another app is using port 4318. Only one copy of Stage Timer can run at once. Quit any other copy, then click Try Again.

My phone or another screen can't connect. In Settings → Integrations, turn on Allow local network access. Make sure both devices are on the same Wi-Fi or network. If macOS asks whether Stage Timer can find devices on your local network, click Allow.

How do I set up Stream Deck or Companion? In Settings → Integrations, click Save Stream Deck plugin… or Save Companion module…, then follow the steps shown there.

Does it need the internet? No. Everything runs on your Mac and your local network.
